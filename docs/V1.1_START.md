# FilmKompass 1.1 – Start und Sicherung

Windows 10/11 x64. ZIP vollständig in einen beschreibbaren Ordner entpacken, anschließend FilmKompass.exe starten. Der komplette `_internal`-Ordner gehört dazu. Keine Administratorrechte oder separate Python-Installation erforderlich. EXE unsigniert; offizielle Quelle und SHA256SUMS.txt verwenden.

Öffentliche Moviepilot-Profilbewertungen laden oder XLSX/CSV importieren. Bibliothek durchsuchen, filtern und in Liste oder Miniaturen (Klein/Mittel/Groß) ansehen. Unterstützte öffentliche Filmlisten separat speichern und mit der eigenen Bibliothek abgleichen; Empfehlungsabgleich vergleicht eingefügte Titel. Nicht jede Liste ist abrufbar; Zugriffssperren werden respektiert. Es werden keine Filme oder Videos heruntergeladen.

Für optionale Onlinecover unter Einstellungen & Daten einen **persönlichen Fanart.tv API Key** eintragen, speichern und Verbindung prüfen. Kostenloser persönlicher Schlüssel: https://fanart.tv/get-an-api-key/ – keine Entwicklerregistrierung und kein Project Key erforderlich. Automatik bewusst aktivieren; eigene Bilder haben Vorrang. Ein Entwickler-Project-Key bleibt für bestehende Konfigurationen optional unterstützt. Keine echten Schlüssel sind enthalten.

Excel/CSV exportiert Bewertungen, nicht das ganze Profil. Datenbanksicherungen enthalten Bildzuordnungen; Bilddateien für einen Rechnerwechsel zusätzlich sichern. Persönliche Daten liegen standardmäßig unter `%LOCALAPPDATA%/MoviepilotManager`. Zwei Instanzen nicht auf dasselbe Profil richten. Vollständiges Profillöschen erstellt vorher eine geprüfte externe Sicherung unter dem von Windows gemeldeten Dokumenteordner in FilmKompass/Sicherungen. Archive können private Schlüssel enthalten: nicht öffentlich weitergeben.

Kurzanleitung in der Anwendung. Updates freiwillig manuell oder höchstens täglich, standardmäßig deaktiviert; keine automatische Installation. Offline bleiben lokale Daten, Listenvergleiche und gespeicherte Bilder nutzbar.

Windows-10-/11-Hauptfunktionen und das korrigierte Taskleistensymbol wurden vom Nutzer praktisch bestätigt. Eine neue Windows-10-Prüfung dieses finalen Pakets wird nicht behauptet. Persönlicher Fanart-Key allein technisch mit simulierten Antworten geprüft; kein gültiger persönlicher Live-Testkey lag beim Entwicklertest vor.
